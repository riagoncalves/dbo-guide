# Flight Quests
---

![](../_images/skills/flight.png) Flight is learned in three steps spread over levels 15, 25 and 30. The first two give temporary **flight scrolls**, and the last one gives the permanent skill.

| Part | Level | Reward |
| - | - | - |
| 1 | 15 | Flight scrolls and the basic flying tutorials |
| 2 | 25 | Flight scrolls for the fastest flight stage |
| 3 | 30, adult with a Master Class | Permanent Flight skill and 10 boost scrolls |

## Flying Basics

- Double-tap `Space` to take off.
- Flying consumes **AP** (Air Points). When AP runs out you fall. AP recovers while you are on the ground.
- A flight scroll lasts about **3 minutes**. Boost scrolls enable the fastest flying speed and make your aura visible.

## Part 1 – Level 15

Talk to the flight NPC in your race's starting zone. For Namekians it is a warrior hovering next to the map revealer.

1. Complete his monster hunting quest to receive a **flight scroll**.
2. Use the scroll and follow the on-screen instructions: the first scroll asks you to fly around.
3. Talk to him again for a second hunting quest and another scroll. This one teaches the **air dash**, and a third teaches the prolonged dash.

## Part 2 – Level 25

This part takes place in **Korin Forest**.

1. Talk to the first flight NPC, who sends you to a second one nearby.
2. The second NPC asks you to defeat some monkeys.
3. Return to the first NPC to learn the fastest flight stage through new scrolls.

## Part 3 – Level 30

You must be level 30, adult and have your [Master Class](character/adult-and-master-class.md).

Return to the second NPC from Part 2. His main quest points to three towers around the central village of Korin Forest. Each tower has an NPC with **three quests**, which can be done in any order.

### North West Tower
| Quest | Objective |
| - | - |
| A | Defeat **12 Red Pants bulls** in the fields next to the Red Pants dungeon. Only the **brown bulls with red shorts and no shirt** count. |
| B | Defeat **8 Red Pants bulls** of another type: **brown with red shorts, a blue shirt and a blue hat**. The first few kills may not count. |
| C | Defeat one **Super** monster at the marked spot |

### North East Tower
| Quest | Objective |
| - | - |
| A | Defeat one marked monster |
| B | Find and open **one crate**. The three circles on the map are possible locations. |
| C | Defeat one marked monster |

### South East Tower
| Quest | Objective |
| - | - |
| A | Collect **5** plants at the marked location |
| B | Collect **10** flowers at the marked location |
| C | Defeat one **Super** monster |

When all nine quests are done, return to the main quest giver. You receive **10 boost scrolls** and the permanent **Flight** skill.
