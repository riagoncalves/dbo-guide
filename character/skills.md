# Skills, RP & HTB
---

## Skill Tree

Press `K` to open the skill window. It has your base class tree, your Master Class tree (after level 30) and the **Action Skills** tab with utilities such as picking up items, opening a private shop, rolling dice and emotes.

- Every level grants **1 Skill Point**. Learning a skill or raising it by one level always costs 1 SP.
- Click the `+` on a skill to learn or upgrade it. Hover the skill or the `+` to see its current level, effect, cooldown and whether it can still be upgraded.
- Drag skills from the tree to the hotbar to use them.
- Passive skills are on the right side of the tree. Some cost SP, some come from quests and some from wishes to Shenron.

| Icon colour | Skill type |
| - | - |
| Red | Physical damage |
| Blue | Energy damage |
| Green | Buff |
| Purple | Debuff |

## Rage Points (RP)

The RP bar fills when you are hit and when you charge with `Z`. Each time it fills you gain one **RP ball**, shown as a yellow orb under the bar.

- You gain an extra RP ball slot every **10 levels**.
- RP gradually drains while you are out of combat.
- **Press and hold** a skill key instead of tapping it to open the RP menu, then click an effect or press its number. If you do not choose within 2 seconds the skill is cancelled.
- Each RP effect costs one RP ball. A few skills cost two.
- In the skill tree, the small icon above the `+` of a skill sets its **default RP effect**, so holding the key applies it automatically. Greyed out effects unlock when the skill reaches the level shown.

### RP Effects

| Effect | Result |
| - | - |
| Power | Increases the damage of the skill |
| Knockdown | Adds a chance to knock the target down. It can fail. |
| Duration | Makes the skill's effect last longer |
| Cooldown | Shortens the cooldown of the skill |
| Guard Break | PvP only. Deals **250%** damage to a target that is guarding, but **0** damage if the target is not guarding |
| Cast Time | Shortens the cast time, usually by about 0.6 seconds |
| EP Save | Lowers the EP cost. Very useful for healers |

### Knockdown
A knocked down character cannot act and takes more damage until they stand up. Move the mouse quickly from side to side to get up faster.

## HTB (Hyper Tension Blow)

HTBs are cinematic rush attacks that end with a big finisher. They need RP and have a **1 hour** cooldown.

- The first HTB is a reward of the [Adult quest](character/adult-and-master-class.md) at level 30.
- Each Master Class has a second HTB, which is obtained through a [wish to Shenron](dragon-balls/overview.md).

## Transformations

Each race has one transformation, obtained by wishing for it from Shenron with a set of hunted Dragon Balls. The wishes are level restricted: Super Saiyan, for example, cannot be wished for before level 40.

| Race | Transformation | Effect |
| - | - | - |
| Human | Super Saiyan | Hair and aura change. Movement speed, attack speed and EP increase. When it ends the character needs a few seconds to catch their breath. |
| Namekian | Great Namek | The character grows to giant size. Attack rises sharply and movement slows down. Only basic attacks and transformation skills can be used. |
| Majin | Pure Majin | Takes the shape of Kid Buu. Attack and defense rise sharply and movement slows down. Only a small set of powerful skills can be used, such as Planet Burst and Genocide Blast. |

Transformations drain EP or last a fixed time. You return to normal when the time runs out or when EP drops to 10%, and the skill then has a **1 hour** cooldown.
