# Guilds & Dojos
---

## Creating a Guild

Talk to a **Guild Manager** in a major village, such as the starting towns.

| Requirement | Value |
| - | - |
| Party | A full party of **5** players, all present |
| Founder | Must be the party leader and at least **level 30** |
| Fee | **200,000** Zeni |
| Name | Up to 16 characters. It cannot be changed afterwards. |

All five party members join the new guild and the founder becomes **Guild Master**.

## Managing a Guild

- Press `G` to open the guild window. It shows the emblem, the dojo, the guild points, the notice and the level, class and location of every member.
- Only the Guild Master and the **Jr. Masters** can invite players.
- The Guild Master can expel members. Anyone can leave with the Leave Guild button.
- Guild chat (`/g`) works across all channels.

## Guild Points

A new guild holds **20** members. To grow it, members donate Zeni to the **Guild Merchant**: every **10,000 Zeni** donated gives **5 guild points**. Only the Guild Master can spend them.

| Points | Feature unlocked |
| - | - |
| 1,000 | Guild Bank |
| 2,000 | 30 members |
| 3,000 | 2nd Jr. Master |
| 4,000 | 40 members |
| 6,000 | 50 members |
| 7,000 | 3rd Jr. Master |
| 8,000 | Create a guild emblem |
| 9,000 | 60 members |
| 10,000 | 70 members |
| 11,000 | 4th Jr. Master |
| 12,000 | 80 members |
| 14,000 | Change the guild emblem |

The emblem has three layers: pattern, frame and background colour. Once set, it floats next to the guild name above every member.

### Owning a Dojo

| Requirement | Value |
| - | - |
| Guild points | At least **10,000** |
| Price | **5,000,000** Zeni |
| Applicant | Only the Guild Master, through the Guild Manager |

### Benefits
- The Guild Master and one chosen member enter the [Tenkaichi Budokai](pvp/budokai.md) directly, without preliminaries.
- Five separate training areas.
- A supply room with exclusive items and merchants for buying and selling.
- A **Dojo Bank** used by the Guild Master.

## Dojo Scramble

A guild that meets the ownership requirements can challenge the owner of a dojo.

| Rule | Value |
| - | - |
| Challenge fee | **1,000,000** Zeni, paid by the challenging Guild Master |
| Start time | 6:00 AM server time |
| Refusing | The owner may refuse the challenge by paying **100,000,000** Zeni in compensation |
| Players | Up to **30** per side |
| Time limit | **60 minutes** |
| Victory | First guild to **500 points** |
| Tie | The defending guild keeps the dojo |

Points come from capturing the **seals** in the five rooms of the dojo. Defeated players respawn at their own side's starting point, north or south.
