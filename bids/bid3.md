# BID 3 - Cell-X
---

## Overview

| Info | Details |
| - | - |
| Dungeon | Abandoned Cave |
| Location | Behind a waterfall in the Kame House area, Papaya Island |
| Boss | Cell-X |
| Boss attribute | None |

Cell-X is Cell revived by the Time Breakers. He was first hidden in [Captain Bacterian's Hideout](bids/bid2.md) while the pirates gathered energy for him, but grew impatient and settled in an abandoned cave behind a waterfall, where he breeds his own Bio-Androids.

## Enemies

| Enemy | Notes |
| - | - |
| Bio-Androids | Creatures spawned by Cell-X |
| Cell-X Jr. | Spawned by Cell-X, like the Cell Jrs. of the original Cell |
| Cell-X | Boss |
