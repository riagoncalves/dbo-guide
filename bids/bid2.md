# BID 2 - Captain Bacterian
---

![Captain Bacterian](../_images/bacterian/bacterian.png)

## Overview

| Info | Details |
| - | - |
| Dungeon | Captain Bacterian's Hideout |
| Location | Kame House area, Papaya Island |
| Boss | Captain Bacterian |
| Boss LP | 1,645,300 |

Captain Bacterian is a filthy pirate captain allied with the Time Breakers. Towa ordered him to gather energy on Papaya Island to feed the growth of Cell-X, which he kept hidden in his hideout until Cell-X lost patience and moved to a nearby cave ([BID 3](bids/bid3.md)).

## Drops

Captain Bacterian drops the **Bacterian Golden** Legendary weapons, which have a higher base damage than the other Legendary weapons of the same level.
